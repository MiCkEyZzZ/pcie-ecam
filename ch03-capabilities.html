PCIe ECAM Host Bridge

3.5. Список возможностей

Возможности — расширяемые блоки регистров, на которые указывает поле Capabilities Pointer (0x34).

Структура

Каждая запись начинается с двух байтов:

СмещениеРазмерПоле
+01Capability ID
+11Next Pointer

Конец списка — Next = 0x00.

0x34 ─▶ 0x40: ID=0x01, next=0x50 (Power Management)
        0x50: ID=0x05, next=0x60 (MSI)
        0x60: ID=0x10, next=0x70 (PCI Express)
        0x70: ID=0x11, next=0x00 (MSI-X)

Перебор

#![allow(unused)]
fn main() {
pub fn for_each_cap(
    cfg: &impl ConfigSpace,
    a: Address,
    mut f: impl FnMut(u8, u8) -> bool,
) -> Result<(), Error> {
    let status = cfg.read16(a, 0x06)?;
    if status & 0x0010 == 0 {
        return Ok(());          // списка нет
    }

    let mut ptr = cfg.read8(a, 0x34)? & 0xFC;
    let mut guard = 0;

    while ptr != 0 && guard < 48 {
        let id = cfg.read8(a, ptr)?;
        let next = cfg.read8(a, ptr + 1)?;

        if !f(ptr, id) {
            break;
        }
        if next == ptr {
            break;              // защита от петли
        }

        ptr = next & 0xFC;
        guard += 1;
    }
    Ok(())
}
}

MSI (0x05)

Состав зависит от разрядности адреса (бит 7 в Message Control):

Смещение32-битный адрес64-битный адрес
+0x00ID / Next / Message Controlто же
+0x04Message AddressMessage Address, младшие 32
+0x08Message DataMessage Address, старшие 32
+0x0CMask Bits (если есть)Message Data
+0x10Pending BitsMask Bits (если есть)
+0x14—Pending Bits

Поле Message Data задаёт вектор; адрес указывает в пространство контроллера прерываний.

MSI-X (0x11)

СмещениеПоле
+0x00ID / Next / Message Control
+0x04Table Offset / BIR
+0x08PBA Offset / BIR

Таблица MSI-X лежит в BAR, указанном в BIR, по смещению из Table Offset. Каждая запись — 16 байт.

Практическое замечание

Список возможностей может быть невыровненным по 4 байта, но на практике указатели кратны четырём. Чтение байтовыми обращениями надёжнее, чем чтение словами, если реализация не гарантирует доступ к отдельным байтам.

Порядок использования

1. Проверить бит Capabilities List в Status.
2. Пройти список, собрать смещения нужных возможностей.
3. Работать с найденными блоками по их собственным правилам.
4. Не предполагать порядок возможностей в списке.
