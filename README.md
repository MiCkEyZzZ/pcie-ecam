# PCIe ECAM Host Bridge

Русскоязычное техническое руководство по host bridge с доступом
к configuration space через ECAM (MCFG), собранное на mdBook.

Книга описывает механизм ECAM, формат configuration space,
алгоритм перечисления шины и устройство `no_std`-драйвера.

## Сборка

```console
$ mdbook build      # результат в ./book
$ mdbook serve      # предпросмотр на http://localhost:3000
```

## Базовые сведения

| Параметр | Значение |
|----------|----------|
| Шина | PCI Express |
| Доступ к конфигурации | ECAM, memory-mapped |
| Объём на функцию | 4 КБ |
| Шин в сегменте | 256 |
| Устройств на шине | 32 |
| Функций на устройстве | 8 |
| Стандартное пространство | 256 байт |
| Расширенное пространство | 4 КБ |

Текст написан самостоятельно и описывает технические факты
и принципы работы. Спецификации PCI-SIG здесь не воспроизводятся.
