# 2.3. Раскладка окна ECAM

Окно ECAM непрерывно, но внутри него действует строгая структура.

## Раскладка внутри функции

| Смещение | Область |
|----------|---------|
| `0x000`–`0x03F` | Заголовок функции |
| `0x040`–`0x0FF` | Регистры, зависящие от типа |
| `0x100`–`0xFFF` | Расширенные возможности |

Точная граница зависит от типа заголовка: у типа 0 и типа 1
заголовок занимает 64 байта, дальше идут BAR и служебные поля.

## Выравнивание

| Что | Требование |
|-----|------------|
| Функция | 4 КБ |
| Устройство | 32 КБ |
| Шина | 1 МБ |

Из этого следует, что младшие 12 бит адреса функции — это
смещение, а старшие биты определяют положение функции в окне.

## Пример

```text
ECAM_BASE = 0x4010_0000

Адрес функции 0000:00:03.0:
  0x4010_0000 + (0 << 20) + (3 << 15) + (0 << 12)
= 0x4010_0000 + 0x1_8000
= 0x4011_8000

Адрес регистра Vendor ID (0x00):
  0x4011_8000

Адрес BAR0 (0x10):
  0x4011_8010
```

## Плотность

| Уровень | Сколько адресов | Сколько занято |
|---------|-----------------|----------------|
| Шина | 1 МБ | до 32 × 8 функций |
| Устройство | 32 КБ | до 8 функций |
| Функция | 4 КБ | до 4 КБ |

Большая часть окна может быть пустой. Это нормально: аппаратура
декодирует адрес целиком, а не ищет занятые области.

## Окно и диапазон шин

Прошивка описывает не всё 256-мегабайтное пространство, а только
используемые шины:

```text
ECAM_BASE ──────────────▶ bus 0
           + 1 МБ ─────▶ bus 1
           + 2 МБ ─────▶ bus 2
           ...
           + N МБ ─────▶ bus N
```

Размер окна = `(end_bus - start_bus + 1) × 1 МБ`.

## Смещение внутри окна

Если окно начинается не с шины 0, то адрес считается так:

```text
addr = ECAM_BASE + ((bus - start_bus) << 20) + ...
```

Некоторые реализации всё равно выделяют окно от шины 0, другие
начинают с первой используемой. Это нужно проверять по описанию
прошивки, а не предполагать.

## Чтение за пределами окна

Обращение за границу описанного диапазона:

- может вернуть `0xFFFFFFFF`;
- может вызвать ошибку шины;
- может молча зависнуть на медленной шине.

Драйвер обязан проверять границы до вычисления адреса.
