# 2.8. Перечисление шины

Перечисление — обход дерева PCIe от корневой шины вниз.

## Схема

```text
scan_bus(bus):
    for dev in 0..32:
        vendor = read16(bus, dev, 0, 0x00)
        if vendor == 0xFFFF: continue

        header = read8(bus, dev, 0, 0x0E)
        functions = if header & 0x80 { 0..8 } else { 0..1 }

        for fn in functions:
            vendor = read16(bus, dev, fn, 0x00)
            if vendor == 0xFFFF: continue

            if is_bridge(bus, dev, fn):
                sec = alloc_bus()
                program_bridge(bus, dev, fn, sec)
                scan_bus(sec)
                set_subordinate(bus, dev, fn, max_bus_used)
            else:
                register_function(bus, dev, fn)
```

## Порядок обхода

Обход в глубину:

```text
bus 0
 ├── dev 1 (мост) ──▶ bus 1
 │                     ├── dev 0
 │                     └── dev 2 (мост) ──▶ bus 2
 ├── dev 2
 └── dev 3
```

Номера шин назначаются по мере спуска: первый мост получает
следующий свободный номер, всё его поддерево занимает диапазон,
затем нумерация продолжается.

## Назначение номеров

| Шаг | Действие |
|-----|----------|
| 1 | Взять следующий свободный номер `n` |
| 2 | Записать `n` в `Secondary Bus Number` моста |
| 3 | Записать `n` во временное значение `Subordinate Bus Number` |
| 4 | Просканировать шину `n` |
| 5 | Записать фактический максимум в `Subordinate Bus Number` |

Шаг 5 важен: во время сканирования мост должен пропускать
транзакции ко всем шинам поддерева, иначе обращения к устройствам
за ним не дойдут.

## Проверка типа

```rust
fn is_bridge(cfg: &impl ConfigSpace, a: Address) -> bool {
    matches!(cfg.read8(a, 0x0E).map(|h| h & 0x7F), Ok(0x01))
}
```

## Обнаружение конца диапазона

Сканирование ограничено диапазоном из прошивки:

```text
если bus > end_bus:
    остановиться и сообщить об ошибке
```

Без этого ограничения обход может уйти в несуществующие шины
и подвесить систему.

## Устройства с несколькими функциями

```rust
let header = cfg.read8(a, 0x0E)?;
let multi = header & 0x80 != 0;

let last_fn = if multi { 8 } else { 1 };
for fn in 0..last_fn {
    ...
}
```

Проверять `multi` нужно только у функции 0: остальные функции
не содержат достоверного признака.

## Что делать с ошибками

| Ошибка | Реакция |
|--------|---------|
| Таймаут чтения | Пропустить функцию, записать в лог |
| `0xFFFF` | Штатное отсутствие устройства |
| Некорректный заголовок | Пропустить устройство |
| Ошибка записи в мост | Прервать перечисление |

## Результат

После обхода драйвер имеет:

- список функций с адресами;
- дерево шин с назначенными номерами;
- информацию о мостах для распределения ресурсов.
