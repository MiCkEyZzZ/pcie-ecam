# О руководстве

Книга описывает host bridge, который даёт процессору доступ
к configuration space устройств PCI Express через механизм ECAM.

## Что описано

| Глава | Содержание |
|-------|------------|
| 1 | Роль моста, место ECAM в топологии, задачи драйвера |
| 2 | Как устроен ECAM: адресация, окна, MCFG, перечисление |
| 3 | Карта configuration space: поля, BAR, возможности |
| 4 | Проектирование `no_std`-драйвера: API, ошибки, инициализация |
| 5 | Интеграция: ACPI, дерево устройств, особенности кремния |
| 6 | Разбор эталонной реализации из ядра Linux |
| 7 | Как проверять и что обычно ломается |

## Чего здесь нет

- Описания физического уровня PCIe: дифференциальные пары,
  кодирование, тренировка канала.
- Полного описания протокола транзакций TLP.
- Правил назначения прерываний и работы MSI/MSI-X сверх того,
  что нужно для перечисления.
- Характеристик конкретных систем на кристалле.

Всё это предмет отдельных документов, перечисленных в разделе
«Дополнительная литература».

## Как читать

Первые две главы дают общую картину. Глава 3 — справочник
по configuration space. Глава 4 — практическая: в ней описан
драйвер, который можно перенести в свой проект. Главы 5–7 —
про интеграцию и отладку.

## Терминология

Термины приведены в глоссарии. Названия регистров, полей и сигналов
выделены `моноширинным` шрифтом. Числа без префикса — десятичные,
с префиксом `0x` — шестнадцатеричные, с префиксом `0b` — двоичные.

## Правовая оговорка

Текст написан самостоятельно и описывает технические факты
и принципы работы. Спецификации PCI Express и PCI Firmware
принадлежат PCI-SIG; дословного перевода их текста здесь нет.
