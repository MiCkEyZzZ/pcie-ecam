# 5.4. DMA и когерентность

Доступ к конфигурации — только часть работы моста. Устройствам
нужно ещё писать в память.

## Что нужно устройству

| Условие | Где настраивается |
|---------|-------------------|
| Разрешение bus master | Бит 2 в Command |
| Адрес для DMA | BAR или регистры устройства |
| Трансляция адреса | IOMMU или окна моста |
| Когерентность | Свойства платформы |

## Включение bus master

```rust
let mut cmd = cfg.read16(a, 0x04)?;
cmd |= 0x0004;
cfg.write16(a, 0x04, cmd)?;
fence();
```

Порядок: сначала BAR и декодирование памяти, затем bus master.
Иначе устройство начнёт писать по неверному адресу.

## Адреса DMA

Устройство видит адреса шины, а процессор — физические или
виртуальные. Соответствие задаётся:

| Механизм | Что делает |
|----------|------------|
| Прямое соответствие | Адрес шины = физический адрес |
| Окна трансляции | Мост сдвигает диапазон |
| IOMMU | Полная таблица трансляции |

Драйвер устройства должен получить адрес, пригодный для
устройства, а не просто физический адрес.

## Когерентность

| Свойство платформы | Что делать |
|--------------------|------------|
| Когерентная (обычно x86) | Ничего |
| Некогерентная (часто ARM) | Операции поддержания когерентности |

Операции:

```text
1. Перед передачей буфера устройству — сбросить кэш на память.
2. После получения данных — инвалидировать кэш.
3. Барьер до и после.
```

В дереве устройств когерентность выражается свойством
`dma-coherent` у узла моста.

## Границы DMA

| Ограничение | Причина |
|-------------|---------|
| 32-битные адреса | Устройство не умеет больше |
| Окно моста | Транзакции вне окна отбрасываются |
| IOMMU | Нет записи в таблице |

Если устройство поддерживает только 32-битные адреса, буфер
должен быть размещён ниже 4 ГБ. Это проверяется по
`Device Capabilities` в возможности PCI Express.

## Пример

```rust
pub fn prepare_dma(
    cfg: &impl ConfigSpace,
    a: Address,
    buf_phys: u64,
) -> Result<(), Error> {
    if buf_phys > u32::MAX as u64 && !supports_64bit_dma(cfg, a)? {
        return Err(Error::Unsupported);
    }

    let mut cmd = cfg.read16(a, 0x04)?;
    cmd |= 0x0002 | 0x0004;
    cfg.write16(a, 0x04, cmd)?;
    fence();

    Ok(())
}
```

## Ошибки DMA

| Симптом | Причина |
|---------|---------|
| Устройство пишет в никуда | Не включён bus master |
| Данные повреждены | Нет когерентности |
| Работает только под 4 ГБ | Ограничение адресации |
| Ошибки AER | Транзакция вне окна |

## Безопасность

Без IOMMU устройство может писать в любую физическую память.
Меры:

| Мера | Защита |
|------|--------|
| IOMMU | Изоляция по устройству |
| Окна моста | Ограничение диапазона |
| Отключение bus master | Для неиспользуемых устройств |

Драйвер моста обязан включать bus master только тем функциям,
которым это действительно нужно.
