# 3.2. Заголовок типа 0

Заголовок обычной функции занимает 64 байта.

## Идентификация

| Смещение | Размер | Имя | Тип | Описание |
|----------|--------|-----|-----|----------|
| `0x00` | 2 | Vendor ID | RO | Производитель |
| `0x02` | 2 | Device ID | RO | Модель |
| `0x08` | 1 | Revision ID | RO | Ревизия |
| `0x09` | 1 | Prog. Interface | RO | Программный интерфейс класса |
| `0x0A` | 1 | Subclass | RO | Подкласс |
| `0x0B` | 1 | Class Code | RO | Базовый класс |
| `0x0E` | 1 | Header Type | RO | Тип заголовка |

## Управление

| Смещение | Размер | Имя | Тип | Описание |
|----------|--------|-----|-----|----------|
| `0x04` | 2 | Command | RW | Управление декодированием |
| `0x06` | 2 | Status | RO | Состояние |
| `0x0C` | 1 | Cache Line Size | RW | Размер строки кэша |
| `0x0D` | 1 | Latency Timer | RW | Таймер задержки (PCI) |
| `0x0F` | 1 | BIST | RW | Встроенный самотест |

## Ресурсы

| Смещение | Размер | Имя | Тип | Описание |
|----------|--------|-----|-----|----------|
| `0x10` | 4 | BAR0 | RW | Базовый адрес 0 |
| `0x14` | 4 | BAR1 | RW | Базовый адрес 1 |
| `0x18` | 4 | BAR2 | RW | Базовый адрес 2 |
| `0x1C` | 4 | BAR3 | RW | Базовый адрес 3 |
| `0x20` | 4 | BAR4 | RW | Базовый адрес 4 |
| `0x24` | 4 | BAR5 | RW | Базовый адрес 5 |
| `0x30` | 4 | Expansion ROM | RW | Базовый адрес ПЗУ |

## Прочее

| Смещение | Размер | Имя | Тип | Описание |
|----------|--------|-----|-----|----------|
| `0x28` | 4 | CardBus CIS | RO | Указатель на CIS |
| `0x2C` | 2 | Subsystem Vendor | RO | Производитель платы |
| `0x2E` | 2 | Subsystem ID | RO | Модель платы |
| `0x34` | 1 | Capabilities Ptr | RO | Смещение списка возможностей |
| `0x3C` | 1 | Interrupt Line | RW | Номер линии |
| `0x3D` | 1 | Interrupt Pin | RO | Используемый вывод INTx |
| `0x3E` | 1 | Min Grant | RO | Минимальный грант (PCI) |
| `0x3F` | 1 | Max Latency | RO | Максимальная задержка (PCI) |

## Interrupt Pin

| Значение | Вывод |
|----------|-------|
| `0x00` | Не использует INTx |
| `0x01` | INTA# |
| `0x02` | INTB# |
| `0x03` | INTC# |
| `0x04` | INTD# |

Функции PCIe обычно указывают `0x01` и используют MSI,
если он доступен.

## Пример чтения

```rust
let vendor  = cfg.read16(a, 0x00)?;
let device  = cfg.read16(a, 0x02)?;
let class   = cfg.read8(a, 0x0B)?;
let header  = cfg.read8(a, 0x0E)?;
let cmd     = cfg.read16(a, 0x04)?;

if vendor == 0xFFFF {
    return Err(Error::NoDevice);
}
```

## Замечание

BAR имеют смысл только после того, как прошивка или драйвер
записали в них адреса. До этого в них находится описание размера
и типа, а не действительный адрес.
