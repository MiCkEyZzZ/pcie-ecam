# 3.4. Базовые адреса BAR

BAR описывают окна, которые функция просит у системы.

## Расположение

| Смещение | BAR |
|----------|-----|
| `0x10` | BAR0 |
| `0x14` | BAR1 |
| `0x18` | BAR2 |
| `0x1C` | BAR3 |
| `0x20` | BAR4 |
| `0x24` | BAR5 |

## Формат: память

| Бит | Значение |
|-----|----------|
| 0 | 0 — окно памяти |
| 2:1 | Разрядность адреса |
| 3 | Prefetchable |
| 31:4 | Адрес (для 32-битного) |

| Бит 2:1 | Разрядность |
|---------|-------------|
| `0b00` | 32 бита |
| `0b10` | 64 бита |
| другое | Зарезервировано |

## Формат: ввод-вывод

| Бит | Значение |
|-----|----------|
| 0 | 1 — окно ввода-вывода |
| 1 | Зарезервировано |
| 31:2 | Адрес |

## Prefetchable

| Значение | Смысл |
|----------|-------|
| 0 | Чтение имеет побочные эффекты, кэшировать нельзя |
| 1 | Чтение безопасно, можно кэшировать и объединять |

Для регистров управления обычно prefetchable = 0.

## Определение размера

```rust
pub fn bar_size(cfg: &impl ConfigSpace, a: Address, bar: u8) -> Result<u32, Error> {
    let off = 0x10 + 4 * bar as u8;
    let orig = cfg.read32(a, off)?;

    cfg.write32(a, off, 0xFFFF_FFFF)?;
    let mask = cfg.read32(a, off)?;
    cfg.write32(a, off, orig)?;

    if mask == 0 || mask == 0xFFFF_FFFF {
        return Ok(0);       // BAR не реализован
    }
    Ok(!(mask & !0xF) + 1)
}
```

Для 64-битного BAR нужно учесть и старшее слово:

```text
1. Записать 0xFFFFFFFF в оба слова.
2. Прочитать оба.
3. Инвертировать объединённое 64-битное значение.
4. Прибавить единицу.
```

## Типичные размеры

| Устройство | Размер окна |
|------------|-------------|
| Контроллер Ethernet | 128 КБ – 1 МБ |
| NVMe | 16 КБ – 64 КБ |
| xHCI | 64 КБ |
| Видеокарта | 16 МБ – 256 МБ |
| Virtio | 4 КБ – 16 КБ |

## Проверка после записи

```rust
let addr = 0xFE00_0000u32;
cfg.write32(a, 0x10, addr)?;
let back = cfg.read32(a, 0x10)?;

if back & !0xF != addr & !0xF {
    return Err(Error::BarNotWritable);
}
```

Если чтение не совпало, BAR может быть:

- только для чтения (адрес задан аппаратно);
- уже занят;
- не реализован.

## Расширение ROM

Смещение `0x30` содержит адрес ПЗУ расширения. Формат похож
на BAR, но размер фиксирован и определяется по содержимому ПЗУ.
Включается битом `Expansion ROM Enable` в том же регистре.

## Замечание

BAR не является указателем на «память устройства» в обычном
смысле: это адрес окна, в которое отображается память или
регистры. После записи адреса и включения декодирования
обращение по этому адресу уходит на шину PCIe.
