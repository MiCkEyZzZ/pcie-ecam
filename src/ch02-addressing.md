# 2.2. Адресация bus/device/function

Адрес функции в PCIe состоит из трёх чисел, которые исторически
пришли из PCI.

## Номера

| Поле | Диапазон | Примечание |
|------|----------|------------|
| Bus | 0–255 | 0 — обычно корневая шина |
| Device | 0–31 | 32 устройства на шине |
| Function | 0–7 | 8 функций на устройстве |

## Запись адреса

```text
0000:00:1f.2
 │    │  │  └── функция 2
 │    │  └───── устройство 31
 │    └──────── шина 0
 └───────────── сегмент 0
```

Формат `SSSS:BB:DD.F` используется в `lspci`, в именах файлов
`/sys/bus/pci/devices` и в логах.

## Смещения в адресе

| Поле | Сдвиг | Маска |
|------|-------|-------|
| function | 12 | `0x7000` |
| device | 15 | `0xF8000` |
| bus | 20 | `0xFF00000` |
| offset | 0 | `0xFFF` |

```c
uint64_t addr = base
              | ((uint64_t)bus      << 20)
              | ((uint64_t)device   << 15)
              | ((uint64_t)function << 12)
              | (offset & 0xFFF);
```

## Устройства с одной функцией

Устройство может иметь только функцию 0. Признак —
бит 7 регистра `Header Type` (`0x0E`):

| Бит 7 | Значение |
|-------|----------|
| 0 | Одна функция |
| 1 | Несколько функций |

Если бит равен нулю, функции 1–7 проверять не нужно.

## Функция 0 как обязательная

Если у устройства несколько функций, функция 0 должна
присутствовать. Обратное неверно: отсутствие функции 1
не означает отсутствия функции 2.

Поэтому обход всегда идёт по всем восьми номерам, кроме случая,
когда бит multi-function равен нулю.

## ARI

При включённом Alternative Routing-ID Interpretation (ARI)
нумерация меняется: поле device и младшие биты function
объединяются, позволяя до 256 функций на устройстве.

| Режим | Функций на устройство |
|-------|----------------------|
| Обычный | 8 |
| ARI | 256 |

ARI включается в расширенной возможности и меняет формулу адреса.
Драйвер, который её не поддерживает, всё равно корректно работает
с устройствами без ARI.

## Адресация в ECAM и в TLP

| Место | Как задаётся адрес |
|-------|--------------------|
| ECAM | Номер шины, устройства и функции закодирован в адресе памяти |
| TLP | Поля `Bus`, `Device`, `Function` в заголовке |

Контроллер ECAM извлекает их из адреса и подставляет в TLP.

## Практическое замечание

Номер шины — не свойство устройства, а результат назначения.
При перечислении мост получает вторичную шину, и все устройства
за ним видны уже под новым номером. До назначения их адреса
не определены.
