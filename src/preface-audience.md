# Аудитория и соглашения

## Для кого

- разработчиков драйверов и ядер, которым нужен доступ к PCIe
  на `no_std`-платформе;
- инженеров, пишущих загрузчик или гипервизор;
- специалистов, разбирающихся в конфигурации устройств PCIe
  и причинах ошибок перечисления.

Предполагается знакомство с понятиями «регистр», «отображение
в память», «шина» и «прерывание».

## Соглашения

| Обозначение | Значение |
|-------------|----------|
| `RW` | Чтение и запись |
| `RO` | Только чтение |
| `WO` | Только запись |
| `—` | Поле зарезервировано |
| `x` | Значение не определено |
| `0x` | Шестнадцатеричная запись |
| `0b` | Двоичная запись |

## Единицы адресации

| Термин | Что означает |
|--------|--------------|
| `bus` | Номер шины, 0–255 |
| `device` | Номер устройства на шине, 0–31 |
| `function` | Номер функции в устройстве, 0–7 |
| `offset` | Смещение внутри configuration space, 0–0xFFF |
| `segment` | Номер сегментной группы, 0–65535 |

Полный адрес функции записывается как `BB:DD.F`
и дополняется номером сегмента: `SSSS:BB:DD.F`.

## Соглашения об уровнях

| Уровень | Что это |
|---------|---------|
| Устройство | Микросхема или функция на шине |
| Функция | Независимый набор регистров внутри устройства |
| Мост | Функция типа 1, соединяющая две шины |
| Корневой комплекс | Совокупность host bridge и корневых портов |

## Обращения к памяти

Окно ECAM — обычная память, но с особыми свойствами:

- доступ только выровненный, по 4 байта;
- порядок обращений между конфигурацией и MMIO устройства
  не гарантирован без барьеров;
- окно не кэшируется.

## Примеры кода

Примеры написаны на Rust без стандартной библиотеки. Они
иллюстративны: конкретные типы платформы (`PhysAddr`, `Mutex`,
`println!`) заменены на условные.
