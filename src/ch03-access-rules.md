# 3.8. Правила доступа

Configuration space отличается от обычной памяти набором
ограничений, которые нужно соблюдать в драйвере.

## Выравнивание

| Разрядность | Требование |
|-------------|------------|
| 1 байт | Любой адрес |
| 2 байта | Адрес кратен 2 |
| 4 байта | Адрес кратен 4 |

Обращение с нарушением выравнивания на некоторых платформах
приводит к ошибке шины, на других — к неверным данным.

## Границы

```text
offset + width <= 0x1000
```

Проверка обязательна: окно ECAM не защищено от выхода за пределы
функции аппаратно.

```rust
fn check(offset: u16, width: usize) -> Result<(), Error> {
    if offset as usize + width > 0x1000 {
        return Err(Error::OutOfRange);
    }
    if offset as usize % width != 0 {
        return Err(Error::Misaligned);
    }
    Ok(())
}
```

## Отсутствующие функции

| Признак | Значение |
|---------|----------|
| Vendor ID `0xFFFF` | Функции нет |
| Чтение зависает | Платформа не поддерживает безопасный доступ |
| Ошибка шины | Нужен обработчик |

Первое чтение всегда должно быть защищено таймаутом или
диапазоном, полученным от прошивки.

## Запись в регистры только для чтения

Запись игнорируется, но чтение после записи вернёт прежнее
значение. Это нормально и не является ошибкой.

| Регистр | Поведение |
|---------|-----------|
| Vendor ID | Игнорирует запись |
| Class Code | Игнорирует запись |
| Header Type | Игнорирует запись |
| BAR | Принимает адрес |

## Побочные эффекты

| Действие | Эффект |
|----------|--------|
| Чтение статуса ошибки | Может очистить флаг |
| Запись единицы в статус | Очищает бит |
| Запись в BAR | Меняет адрес окна |
| Запись в Command | Мгновенно меняет декодирование |
| Доступ к MSI-X таблице | Меняет маршрутизацию прерываний |

## Кэширование

Окно ECAM не кэшируется. Но даже при правильных атрибутах
страниц возможны переупорядочивания, поэтому после изменения
конфигурации нужен барьер:

```rust
cfg.write16(a, 0x04, cmd)?;
core::sync::atomic::fence(Ordering::SeqCst);
```

## Многопоточность

Configuration space — общий ресурс. Если несколько потоков
меняют BAR или Command, нужна блокировка:

```rust
let _guard = self.lock.lock();
cfg.write32(a, 0x10, addr)?;
```

Без блокировки две операции «прочитать — изменить — записать»
могут перезаписать друг друга.

## Время ожидания

Некоторые устройства медленно отвечают на конфигурационные
обращения сразу после сброса. Практические меры:

| Мера | Когда нужна |
|------|-------------|
| Повтор чтения | После подачи питания |
| Задержка перед перечислением | После сброса шины |
| Ограничение попыток | Чтобы не зациклиться |

## Итог

| Правило | Проверяется |
|---------|-------------|
| Выравнивание | В функции чтения/записи |
| Границы | До вычисления адреса |
| Наличие функции | По Vendor ID |
| Барьер после записи | Перед MMIO |
| Блокировка | При конкурентном доступе |
