# 2.5. Сегментные группы

Сегмент (segment group) — способ иметь несколько независимых
адресных пространств PCI.

## Зачем нужны сегменты

| Причина | Пояснение |
|---------|-----------|
| Больше 256 шин | Один сегмент вмещает только 256 |
| Разные корневые комплексы | Каждый со своей нумерацией |
| Изоляция | Устройства одного сегмента не видны в другом |

## Нумерация

| Поле | Разрядность | Количество |
|------|-------------|------------|
| Segment | 16 бит | 65536 |

Номер сегмента — часть адреса функции, но не часть адреса ECAM.
Окно выбирается по сегменту, а внутри окна действует только
номер шины.

## Отображение в адрес

```text
(segment, bus, device, function, offset)
        │
        ▼
   выбор окна по segment
        │
        ▼
   base + смещение по bus/device/function/offset
```

## Пример: два сегмента

| Сегмент | База окна | Шины |
|---------|-----------|------|
| 0 | `0xE000_0000` | 0x00–0x7F |
| 1 | `0xF000_0000` | 0x00–0x1F |

Устройство `0000:00:01.0` и `0001:00:01.0` — разные функции
с разными окнами, хотя номер шины, устройства и функции совпадает.

## Проблема «сегмент 0 по умолчанию»

Многие драйверы предполагают, что существует только сегмент 0.
Это неверно для больших систем. Корректная реализация:

- хранит список окон;
- ищет окно по номеру сегмента;
- при отсутствии окна возвращает ошибку, а не использует
  первое попавшееся.

```rust
pub fn window_for(&self, segment: u16) -> Result<&EcamWindow, Error> {
    self.windows
        .iter()
        .find(|w| w.segment == segment)
        .ok_or(Error::UnknownSegment)
}
```

## Несколько окон в одном сегменте

Диапазон шин одного сегмента может быть разбит на несколько
окон. Тогда поиск идёт по паре «сегмент + шина»:

```rust
pub fn window_for(&self, segment: u16, bus: u8) -> Result<&EcamWindow, Error> {
    self.windows
        .iter()
        .find(|w| w.segment == segment && w.contains_bus(bus))
        .ok_or(Error::NoWindow)
}
```

## Ограничения

| Ограничение | Следствие |
|-------------|-----------|
| Номер сегмента не виден устройству | Трансляция выполняется мостом |
| Сегменты не пересекаются | Иначе неоднозначность |
| Максимум 65536 | Достаточно для любых практических систем |

## Замечание о DMA

Номер сегмента участвует в идентификации источника DMA: IOMMU
различает устройства по паре `(segment, bus/device/function)`.
Поэтому при включённой трансляции важно сохранять это соответствие.
