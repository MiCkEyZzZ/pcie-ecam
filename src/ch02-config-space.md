# 2.6. Configuration space и его типы

Configuration space — набор регистров, описывающих функцию:
кто она, что умеет, какие окна ей нужны.

## Размеры

| Область | Смещение | Размер | Кто использует |
|---------|----------|--------|----------------|
| Стандартная | `0x000`–`0x0FF` | 256 Б | Все функции |
| Расширенная | `0x100`–`0xFFF` | 3840 Б | Только PCIe |

Расширенная область есть только у функций PCIe. Для устройств
PCI за мостом она не определена.

## Типы заголовков

| `Header Type[6:0]` | Тип | Кто это |
|--------------------|-----|---------|
| `0x00` | 0 | Обычная функция |
| `0x01` | 1 | Мост PCI-PCI |
| `0x02` | 2 | Мост CardBus |
| `0x80` | — | Бит multi-function |

Младшие 7 бит задают тип, старший бит — признак нескольких
функций.

## Что общего у всех типов

| Смещение | Поле |
|----------|------|
| `0x00` | Vendor ID |
| `0x02` | Device ID |
| `0x04` | Command |
| `0x06` | Status |
| `0x08` | Revision ID |
| `0x09` | Programming Interface |
| `0x0A` | Subclass |
| `0x0B` | Class Code |
| `0x0C` | Cache Line Size |
| `0x0D` | Latency Timer |
| `0x0E` | Header Type |
| `0x0F` | BIST |
| `0x34` | Capability Pointer |
| `0x3C` | Interrupt Line |
| `0x3D` | Interrupt Pin |

## Class Code

Три байта `0x09`–`0x0B` описывают класс устройства:

| Байт | Поле | Пример |
|------|------|--------|
| `0x0B` | Base class | `0x02` — сеть |
| `0x0A` | Subclass | `0x00` — Ethernet |
| `0x09` | Programming interface | `0x00` — обычный |

Класс нужен, чтобы найти драйвер, а не для перечисления.

## Проверка наличия

Стандартный способ:

```rust
let vendor = cfg.read16(addr, 0x00)?;
if vendor == 0xFFFF {
    // функции нет
}
```

Значение `0xFFFF` зарезервировано: настоящий vendor ID
не может быть таким.

## Чтение расширенной области

Расширенная область начинается с цепочки возможностей:

```text
0x100 ─┬─ ID (16) ─ Version (4) ─ Next (12)
       │
       └─▶ 0x100 + next ─▶ следующая возможность ─▶ ... ─▶ 0
```

Конец цепочки — нулевое смещение в поле `Next`.

## Почему это важно для драйвера

| Задача | Где искать |
|--------|------------|
| Найти BAR | `0x10`–`0x24` |
| Понять, есть ли MSI-X | Список возможностей |
| Включить AER | Расширенное пространство |
| Узнать серийный номер | Extended capability `0x0003` |

Без расширенной области драйвер увидит только базовые функции.
