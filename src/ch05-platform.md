# 5.5. Порядок запуска на плате

Ниже — последовательность, которая работает на большинстве
платформ.

## Этапы загрузки

```text
Boot ROM
  └─▶ загрузчик
        ├─ инициализация клока PCIe
        ├─ тренировка линий (аппаратно)
        ├─ чтение MCFG или дерева устройств
        ├─ отображение окна ECAM
        └─ перечисление
              └─▶ ядро
                    ├─ повторная проверка
                    ├─ распределение ресурсов
                    └─ запуск драйверов устройств
```

## Что делает загрузчик

| Шаг | Обязательность |
|-----|----------------|
| Включить питание и клок | Да |
| Дождаться тренировки | Да |
| Найти окно | Да |
| Отобразить окно | Да |
| Проверить корневую функцию | Желательно |
| Перечислить | По необходимости |

Многие загрузчики ограничиваются поиском окна и передают
перечисление ядру.

## Проверка готовности

```rust
fn wait_link(root: Address, cfg: &impl ConfigSpace) -> Result<(), Error> {
    for _ in 0..1000 {
        let vendor = cfg.read16(root, 0x00)?;
        if vendor != 0xFFFF && vendor != 0x0000 {
            return Ok(());
        }
        delay_ms(1);
    }
    Err(Error::Timeout)
}
```

## Отображение окна

| Параметр | Значение |
|----------|----------|
| Атрибуты | Device, не кэшируемая |
| Права | Чтение и запись |
| Исполнение | Запрещено |
| Размер страниц | По размеру окна |

## Передача ядру

| Способ | Что передаётся |
|--------|----------------|
| ACPI | Таблицы как есть |
| Дерево устройств | Узел с `reg` |
| EFI | Указатель на конфигурацию |
| Прямые параметры | База и диапазон шин |

## Типичные проблемы платы

| Проблема | Признак |
|----------|---------|
| Нет клока | Устройства не видны |
| Линия не тренируется | Link Status показывает ошибку |
| Питание не подано | Все ID `0xFFFF` |
| Сброс не снят | Устройства не отвечают |
| Неверный адрес окна | Данные мусорные |

## Проверка после загрузки

```console
$ lspci -nn
$ lspci -vvv -s 00:00.0
$ cat /proc/iomem | grep -i pci
$ dmesg | grep -i -E 'pci|ecam|mcfg'
```

| Что смотреть | О чём говорит |
|--------------|---------------|
| Список устройств | Перечисление работает |
| BAR в `lspci -v` | Ресурсы распределены |
| `/proc/iomem` | Окна не конфликтуют |
| Сообщения об ошибках | Проблемы доступа |

## Разделение ответственности

| Компонент | Отвечает за |
|-----------|-------------|
| Прошивка | Окно, тренировка, базовые ресурсы |
| Загрузчик | Отображение, при необходимости перечисление |
| Ядро | Распределение, драйверы, управление питанием |
| Драйвер устройства | Свои регистры, DMA, прерывания |

Дублирование работы допустимо, но должно быть идемпотентным:
повторное перечисление не должно менять уже назначенные номера
шин и адреса без необходимости.
