# PCIe ECAM Host Bridge

## Техническое руководство

Host bridge — корневой мост шины PCI Express: он связывает процессор
с деревом устройств PCIe и предоставляет доступ к их configuration
space. В современных системах этот доступ почти всегда идёт через
**ECAM** (Enhanced Configuration Access Mechanism) — окно памяти,
в которое отображается конфигурационное пространство всех шин,
устройств и функций.

Эта книга описывает механизм ECAM, формат configuration space,
алгоритм перечисления шины и устройство `no_std`-драйвера, который
всё это реализует.

### Базовые сведения

| Параметр | Значение |
|----------|----------|
| Шина | PCI Express |
| Доступ к конфигурации | ECAM, memory-mapped |
| Объём на функцию | 4 КБ |
| Шин в сегменте | 256 |
| Устройств на шине | 32 |
| Функций на устройстве | 8 |
| Стандартное пространство | 256 байт |
| Расширенное пространство | 4 КБ |

Адреса и параметры окна ECAM задаются прошивкой — через таблицу
MCFG в ACPI или через узел `pci-host-ecam-generic` в дереве
устройств.
