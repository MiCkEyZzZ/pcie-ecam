# 1.1. Что такое host bridge

Host bridge — это функция, которая соединяет процессорную сторону
системы с шиной PCI Express. Через неё процессор получает доступ
к устройствам, а устройства — к памяти.

## Что делает мост

| Функция | Пояснение |
|---------|-----------|
| Формирует шину PCIe | Создаёт корневую шину с номером 0 |
| Отображает configuration space | Делает конфигурацию доступной через окно памяти |
| Транслирует адреса | Сопоставляет адреса CPU и адреса шины |
| Маршрутизирует прерывания | Передаёт INTx и MSI в контроллер прерываний |
| Ограничивает DMA | Через IOMMU или окна трансляции |

## Почему это не «просто мост»

В отличие от моста PCI, корневой комплекс PCIe не является
прозрачным. Он:

- не имеет собственного configuration space;
- не пересылает конфигурационные транзакции как обычные TLP —
  в PCIe они идут через механизм ECAM или устаревший механизм
  через пару портов ввода-вывода;
- управляет нумерацией шин, а не получает её извне.

## Из чего состоит

```text
CPU
 │
 ▼
Host bridge ──▶ корневой порт 0 ──▶ шина 1 ──▶ устройство
 │                         │
 │                         └──▶ шина 2 ──▶ мост ──▶ устройства
 │
 └──▶ окно ECAM (configuration space всех шин)
```

Корневой комплекс может содержать несколько корневых портов.
Каждый порт начинает своё поддерево, но все они обычно видны
через одно окно ECAM или через несколько соседних окон.

## Что видит программное обеспечение

С точки зрения кода мост — это:

1. **Окно памяти**, по которому читается и пишется configuration
   space.
2. **Набор окон** для памяти и ввода-вывода, выделяемых устройствам.
3. **Способ нумерации** шин при перечислении.
4. **Маршрутизация прерываний**.

Первое — предмет этой книги. Остальное рассматривается лишь
настолько, насколько нужно для перечисления и запуска устройств.

## Отличие от «моста» в дереве устройств

В дереве устройств термин «мост» означает узел, у которого есть
свойство `device_type = "pci"` и диапазоны `ranges`. В PCIe
терминологии это соответствует корневому комплексу, а не отдельной
функции типа 1.
