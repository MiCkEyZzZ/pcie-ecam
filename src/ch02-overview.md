# 2.1. Обзор механизма ECAM

ECAM отображает configuration space всех функций сегмента
в непрерывное окно физической памяти.

## Три уровня адресации

```text
segment  →  bus  →  device  →  function  →  offset
```

| Уровень | Разрядность | Количество |
|---------|-------------|------------|
| segment | 16 бит | 65536 |
| bus | 8 бит | 256 |
| device | 5 бит | 32 |
| function | 3 бита | 8 |
| offset | 12 бит | 4096 байт |

## Формула

```text
addr = ECAM_BASE
     + (bus      << 20)
     + (device   << 15)
     + (function << 12)
     + offset
```

Слагаемые не пересекаются, поэтому адрес вычисляется без таблиц
и проверок на пересечение.

## Размеры

| Что | Объём |
|-----|-------|
| Одна функция | 4 КБ |
| Одно устройство (8 функций) | 32 КБ |
| Одна шина (32 устройства) | 1 МБ |
| 256 шин | 256 МБ |

Именно 256 МБ — типичный максимальный размер окна для сегмента.
На практике прошивка описывает только реально используемый
диапазон шин, поэтому окно бывает меньше.

## Что находится в окне

```text
ECAM_BASE
 ├── bus 0
 │    ├── dev 0
 │    │    ├── fn 0  (4 КБ)
 │    │    ├── fn 1
 │    │    └── ... fn 7
 │    ├── dev 1
 │    └── ... dev 31
 ├── bus 1
 └── ... bus N
```

Пустые места тоже присутствуют: окно покрывает все комбинации
в диапазоне, независимо от того, есть ли там устройство.

## Почему 4 КБ на функцию

| Область | Размер | Назначение |
|---------|--------|------------|
| Стандартная | 256 байт | Совместимость с PCI |
| Расширенная | 3840 байт | Возможности PCIe |

Оставшееся место внутри 4 КБ отведено под расширенные
возможности и зарезервировано.

## Атрибуты окна

| Свойство | Значение |
|----------|----------|
| Тип памяти | Device, не кэшируемая |
| Выравнивание доступа | 4 байта |
| Атомарность | Отсутствует между регистрами |
| Побочные эффекты | Чтение может изменить состояние устройства |

Последний пункт важен: некоторые регистры очищаются при чтении,
поэтому «просто посмотреть» не всегда безопасно.

## Что делает аппаратура

При обращении к окну контроллер:

1. Проверяет, что адрес попадает в диапазон.
2. Выделяет номер шины, устройства и функции.
3. Формирует configuration-транзакцию.
4. Возвращает данные или ошибку.

Программное обеспечение видит только обычную память.
