# 3.3. Команда и статус

Два 16-битных регистра по смещениям `0x04` и `0x06` управляют
декодированием и сообщают о событиях.

## Command (`0x04`)

| Бит | Имя | Значение |
|-----|-----|----------|
| 0 | IO Space | Разрешить обращения к вводу-выводу |
| 1 | Memory Space | Разрешить обращения к памяти |
| 2 | Bus Master | Разрешить DMA |
| 3 | Special Cycles | Разрешить специальные циклы |
| 4 | Memory Write & Invalidate | Разрешить инвалидацию при записи |
| 5 | VGA Palette Snoop | Слежение за палитрой VGA |
| 6 | Parity Error Response | Реагировать на ошибки чётности |
| 7 | Wait Cycle Control | Управление тактами ожидания |
| 8 | SERR# Enable | Разрешить системную ошибку |
| 9 | Fast Back-to-Back | Быстрые передачи подряд |
| 10 | Interrupt Disable | Запретить INTx |

## Status (`0x06`)

| Бит | Имя | Значение |
|-----|-----|----------|
| 3 | Interrupt Status | Прерывание активно |
| 4 | Capabilities List | Есть список возможностей |
| 5 | 66 MHz Capable | Поддержка 66 МГц |
| 7 | Fast Back-to-Back | Поддержка быстрых передач |
| 8 | Master Data Parity Error | Ошибка данных при DMA |
| 9:10 | DEVSEL Timing | Тайминг выбора устройства |
| 11 | Signaled Target Abort | Устройство прервало транзакцию |
| 12 | Received Target Abort | Получен Target Abort |
| 13 | Received Master Abort | Получен Master Abort |
| 14 | Signaled System Error | Выставлен SERR# |
| 15 | Detected Parity Error | Обнаружена ошибка чётности |

## Что включает драйвер

| Случай | Биты Command |
|--------|--------------|
| Только MMIO | 1 |
| MMIO и DMA | 1, 2 |
| Порты ввода-вывода | 0, 1 |
| Обработка ошибок | 6, 8 |
| Без INTx | 10 |

## Пример

```rust
pub fn enable_device(cfg: &impl ConfigSpace, a: Address) -> Result<(), Error> {
    let mut cmd = cfg.read16(a, 0x04)?;

    cmd |= 0x0002;   // Memory Space
    cmd |= 0x0004;   // Bus Master

    cfg.write16(a, 0x04, cmd)?;
    Ok(())
}
```

## Порядок операций

```text
1. Записать адреса в BAR.
2. Записать Command с нужными битами.
3. Выполнить барьер.
4. Обращаться к MMIO.
```

Нарушение порядка приводит к тому, что устройство не отвечает
или отвечает по неверному адресу.

## Ошибки шины

Биты статуса 11–14 фиксируют аварийные завершения транзакций:

| Бит | Что означает |
|-----|--------------|
| 11 | Это устройство прервало чужую транзакцию |
| 12 | Транзакция устройства прервана целью |
| 13 | Устройство обратилось к несуществующей цели |
| 14 | Сформирована системная ошибка |

Эти биты липкие: запись единицы их очищает. При отладке
их полезно проверять после перечисления — они показывают,
что драйвер обращался туда, где никого нет.

## Interrupt Disable

Бит 10 маскирует INTx. Для функций PCIe, использующих MSI,
его обычно устанавливают: старые прерывания не нужны и могут
мешать.

## Замечание

Command и Status — 16-битные регистры, но доступ к ним возможен
и 32-битным словом по смещению `0x04`. В этом случае младшие
16 бит — Command, старшие — Status.
