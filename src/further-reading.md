# Дополнительная литература

## Спецификации

| Документ | Что взять |
|----------|-----------|
| PCI Express Base Specification | Формат configuration space, ECAM, заголовки, возможности |
| PCI Firmware Specification | Таблица MCFG, правила описанной топологии |
| ACPI Specification | Размещение MCFG среди таблиц, сигнатуры |
| Devicetree Specification | Формат узлов, свойства `reg`, `ranges`, `bus-range` |

## Привязки и код

| Источник | Зачем |
|----------|-------|
| Привязка `pci-host-ecam-generic` в Linux | Обязательные и необязательные свойства узла |
| `drivers/pci/controller/pci-host-generic.c` | Эталонная реализация ECAM |
| `drivers/pci/ecam.c` | Общая логика отображения окна |
| `drivers/pci/probe.c` | Перечисление и распределение ресурсов |
| `pciutils` (`lspci`, `setpci`) | Проверка результата из пользовательского пространства |

## Смежные темы

| Тема | Зачем нужна |
|------|-------------|
| ACPI | Откуда берётся адрес окна ECAM |
| Дерево устройств | То же для платформ без ACPI |
| Управление памятью | Отображение окна, атрибуты страниц |
| Прерывания | MSI/MSI-X, INTx и их маршрутизация |
| IOMMU | Изоляция DMA устройств |

## Практические стенды

- QEMU с машинами `q35` (x86) и `virt` (ARM/RISC-V);
- платы с UEFI, где MCFG можно посмотреть через `acpidump`;
- ядро Linux как эталон: `lspci -vvv -xxx` показывает
  содержимое configuration space.

## Замечание об актуальности

Механизм ECAM стабилен с первых версий PCIe. Меняются расширенные
возможности и правила управления питанием, но формула адреса
и размер окна на функцию остаются прежними.
